# 部屋管理Webアプリ（room-manager）

キャバクラ等の個室の空室管理を行うローカル完結型Webアプリです。外部npmパッケージへの依存はゼロで、Node.js標準機能（`node:http` / `node:sqlite`）のみで動作します。

## 前提

- Node.js v22.5以上（`node:sqlite`を使用するため）
- データはローカルのSQLiteファイル（`data.db`、初回起動時に自動作成）に保存
- 日々の運用にインターネット接続は不要（店内ネットワークのみで完結）。ただし後述の自動アップデートを使う場合は起動時にインターネット接続があるとよい

## 開発環境（Mac）での動作確認

```bash
cd room-manager
node server.js
```

起動後、ブラウザで `http://localhost:3000` を開くとダッシュボードが表示されます。
`npm install` は不要です（外部依存がないため）。

初回起動時、部屋（101〜108）とスタッフ（ユキ/レナ/ミサキ/ハルカ）のサンプルデータが自動投入されます。実運用前に「マスタ管理」画面から実際の部屋・スタッフ名に置き換えてください（不要なサンプルは削除できます）。

## 本番環境（Windows・店内PC）へのセットアップ

配布用の`windows-setup`フォルダをZIP化した`room-manager-windows-setup.zip`を店内PCで展開し、
中の`install.bat`をダブルクリックするだけでセットアップできます（詳細は`windows-setup/README.txt`）。

- Node.jsが入っていなければ自動でダウンロード・同梱（インターネット接続はこの時だけ必要）
- タスクスケジューラに登録し、次回ログオン時から自動でダッシュボードが全画面起動
- デスクトップに手動起動用のショートカットも作成
- アンインストールは同フォルダの`uninstall.bat`

アプリのコード（`server.js`/`db.js`/`routes.js`/`public/`）を更新した後は、
`windows-setup/build-package.sh`をMacで実行すると配布用ZIPを作り直せます。

### 起動時の自動アップデートについて

店内PCがインターネットに接続されている場合、起動のたびに`update-check.js`が
GitHubリポジトリ（[hassan83/room-manager](https://github.com/hassan83/room-manager)）の
`main`ブランチを確認し、最新でなければ自動でアプリ本体（`server.js`/`db.js`/`routes.js`/
`public/`配下）を更新してから起動します。

- `data.db`（利用データ）や、インストーラ・自動起動設定（`install.bat`/`run-app.bat`等）は更新対象外です
- 確認に失敗する、または通信できない場合は何もせず、既存のファイルでそのまま起動します（起動が長時間止まることはありません）
- 更新のたびに再配布ZIPを作って店舗に送る必要はなく、GitHubにpushするだけで次回起動時に反映されます
- ただし、`install.bat`/`uninstall.bat`/`run-app.bat`など起動・インストール周りの仕組み自体を変更した場合は、自動アップデートの対象外なので、これまで通りZIPを作り直して再インストールしてもらう必要があります
- 動作ログは`update-check.log`（インストール先フォルダ内）に出力されます

### （参考）旧手順：手動コピー＋スタートアップフォルダ登録

`start-windows.bat`は、Node.jsが既に入っている前提で手動セットアップする場合の簡易スクリプトとして残しています。`room-manager`フォルダ一式をコピーしてダブルクリックすれば動作しますが、通常は上記の`install.bat`を使うほうが簡単です。

### キオスクモードからの脱出方法（管理者向け）

`--kiosk`起動中は `Alt + F4` でウィンドウを閉じられます。マスタ管理や設定変更が必要な場合は一度閉じて通常のブラウザで `http://localhost:3000` を開いてください。

## データのバックアップ

`data.db`ファイルをコピーするだけでバックアップになります。日次でUSBメモリや別ドライブにコピーする運用を推奨します。

## 機能一覧

- 部屋の空室管理（ダッシュボードでの一覧表示・色分け、ダークモード対応）
- 部屋の担当スタッフ設定（入室登録時に選択。「未選択」のまま登録することも可能。部屋カードから開いた場合はその部屋の前回担当者が初期選択される。空室カードにも前回担当者を軽く表示）
- 開始〜終了までの時間設定（利用時間を分数で直接入力。初期値は設定画面で変更可能、既定60分）
- 入室登録は「待機中」状態で作成され、「▶ スタート」ボタンを押した時点から1コール・退室の時間計測が始まる（登録ミス時は「取消」で空室に戻せる。スタート待ちの間に清掃を済ませられるため、退室後は清掃工程を経ずそのまま空室に戻る）
- 入退室管理（入室登録・スタート・退室処理の3ステップ）
- 「1コール」「退室」を独立した2つのタイマーとして管理し、各部屋カードから±1分／±5分で個別に調整可能
- 2段階のタイマーアラート（1コール到達・退室予定時刻超過とも1秒おきに音声通知／🔕ボタンで個別に停止可）
- 設定画面（⚙️設定）でアラーム音量（0〜200%、0で消音）・通知音の種類（合成音4種＋効果音ファイル3種の計7種類・試聴可、「1コール」「退室」で別々に設定可能）・利用時間の初期値を変更可能
- 履歴のCSV出力（期間指定でダウンロード、Excelでの日本語文字化けを避けるためUTF-8 BOM付き）
- 部屋・スタッフのマスタ管理（追加・削除）
- 起動時にGitHubリポジトリを確認し、更新があれば自動でアプリ本体を最新化してから起動（インターネット接続がある場合。詳細は上記「起動時の自動アップデートについて」参照）

## 通知音ファイルについて

`public/sounds/` 内の効果音ファイル（success1.mp3 / warning1.mp3 / electronic-roulette-flashing1.mp3）は
[効果音ラボ](https://soundeffect-lab.info/) の素材を、アプリの操作音・通知音として組み込んで利用しています
（同サイトの利用規約上、素材そのものの再配布や「効果音を自由に鳴らせるアプリ」は禁止されていますが、
アプリの決まったタイミングで鳴る操作音・通知音として組み込む利用は明示的に許可されています）。
音を差し替える場合は、同じファイル名で`public/sounds/`内のファイルを置き換えてください。
