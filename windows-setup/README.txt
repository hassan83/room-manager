部屋管理アプリ セットアップキット
====================================

■ 同梱物

- install.bat / uninstall.bat ・・・ セットアップ／アンインストール用（このREADMEの内容）
- 操作マニュアル.docx ・・・ 日々の受付・フロント業務での使い方（入室登録、退室処理、
  アラームの止め方、CSV出力など）。現場のスタッフの方に配布・印刷してご利用ください。
- app / scripts ・・・ アプリ本体（通常は直接さわる必要はありません）

■ インストール方法

1. このZIPファイルを、店内PCの好きな場所に展開（解凍）してください。
   （展開後、このフォルダ自体は残しておく必要はありません。インストール先は別の場所になります）
2. 展開してできたフォルダの中の「install.bat」をダブルクリックしてください。
3. 黒い画面（コマンドプロンプト）が開き、自動でセットアップが進みます。
   - Node.js（アプリの動作に必要なソフト）がPCに入っていない場合は、自動でダウンロードします。
     ※この時だけインターネット接続が必要です。普段の運用ではインターネットは不要です。
   - セットアップの最後に「今すぐ起動して動作確認しますか？」と聞かれるので、
     Y を入力してEnterを押すと、その場でダッシュボードが開いて確認できます。
4. 何かキーを押すとウィンドウが閉じます。これでインストールは完了です。

次回からはPCを起動する（ログオンする）だけで、自動的にブラウザでダッシュボードが開きます。

■ 手動で起動したいとき

デスクトップに作成される「部屋管理ボード起動」というショートカットをダブルクリックしてください。

■ アンインストール方法

同じフォルダの中の「uninstall.bat」をダブルクリックしてください。
自動起動の設定が解除されます。アプリ本体やこれまでの利用履歴（データベース）も
削除するかどうかは、その場で確認されます。

■ データの保存場所

C:\Users\（ユーザー名）\AppData\Local\RoomManager\data.db
に保存されます。バックアップを取る場合はこのファイルをコピーしてください。

■ うまくいかないとき

- 「install.bat」実行中に赤い文字でエラーが出て止まってしまう場合、多くは
  Node.jsの自動ダウンロードに失敗しています（インターネット未接続など）。
  インターネットに接続してから、もう一度「install.bat」を実行してください。
- ダッシュボードは普段お使いの既定のブラウザで通常のウィンドウとして開きます。

■ 起動時の自動アップデートについて

このPCがインターネットに接続されている場合、起動するたびに自動で
最新のアプリ内容（GitHub上のroom-managerリポジトリ）を確認し、更新があれば
自動的に取り込んでから起動します。特別な操作は不要です。

- 利用履歴（データベース）が消えることはありません
- インターネットに繋がらない、または確認に失敗した場合は、何もせずこれまで通り
  起動します（起動が長く止まってしまうことはありません）
- インストール・アンインストールの仕組み自体（install.bat等）が変わるような
  大きな更新の場合は、この自動アップデートの対象外です。その場合は下記の方法で
  改めてセットアップし直してください

■ アップデート方法（インストール・アンインストールの仕組み自体を更新する場合）

新しいセットアップキットを受け取ったら、同じ手順で「install.bat」を実行するだけで
アプリ本体だけが上書きされます。利用履歴（データベース）は消えません。

その際、起動中の旧バージョンのサーバーやダッシュボード画面が残っていても、
install.bat が自動的に検知して停止してから上書きするため、PCを再起動したり
事前に手動で閉じたりする必要はありません（自動起動の登録も新しい内容に
置き換わるだけで、二重に登録されることはありません）。
アップデート後は、念のため一度PCを再起動するか、デスクトップの
「部屋管理ボード起動」ショートカットから起動し直して、新しい画面になって
いることをご確認ください。
